# 환영 — 2D 괴도 전투 프로토타입 v0.2

Unity 없이 실행되는 HTML5 Canvas 기반 게임입니다. 별도 라이브러리/빌드 과정이 없습니다.

## 실행
- `index.html`을 브라우저에서 엽니다.
- GitHub 저장소 최상위에 `index.html`, `style.css`, `game.js`를 업로드합니다.
- GitHub 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save**.
- 공개 URL: `https://<사용자명>.github.io/<저장소명>/` (실제 배포 확인 전까지 접속을 보장하지 않음).

## 조작
- ← / →: 좌우 이동
- ↑: 점프
- Z: 빠른 3연속 검술
- X: 흰색 연막 순간이동 (쿨타임 2.5초)
- C: 뒤로 대시하며 폭탄 투척 (쿨타임 4초)
- V: 기세 100일 때 월광 일섬
- R: 재시작
- 모바일: 화면 아래 터치 버튼

## 전투 규칙
- 공격 명중 시 기세 +9, 적 처치 시 +12, 최대 100.
- 기세 100을 사용하면 전방 광역 필살기 발동.
- 적은 플레이어를 추적하고 공격 전에 붉은 예고 표시를 보여줍니다.
- 모든 적 처치 후 다음 웨이브 시작, 체력 17 회복.

## 파일
- `index.html`: UI
- `style.css`: 스타일 및 모바일 컨트롤
- `game.js`: 전투, 적 AI, 이펙트, 물리, HUD

프로토타입으로 제작되었으며 실제 브라우저 환경별 플레이테스트가 필요합니다.
