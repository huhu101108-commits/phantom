# 환영 — 전투 프로토타입 v1.0

## 실행
`index.html`을 브라우저에서 열거나 GitHub Pages에 전체 폴더를 올립니다.

## 조작
- ← / → 이동
- Space 점프
- Z 3연속 검술
- X 흰 연막 순간이동
- C 뒤로 튀어오르며 전방 폭탄 투척
- V 기세 100 소모 필살기
- R 재시작

## 그래픽 설계
- 주인공: 160×160 논리 좌표의 동일한 캐릭터 원형, 320×320 투명 PNG 프레임
- 모자, 은발, 보라색 눈가면, 흰 스카프, 검은 코트, 은빛 검 유지
- 발 기준점 일치, 달리기/점프/검술/연막/폭탄/필살기 전용 자세
- `assets/` 내 프레임 이미지와 `assets/bg/arena.png` 사용
- 새로 그린 벡터 기반 스프라이트이며 이전 원화와 픽셀 단위로 동일하지 않습니다.

## 테스트 한계
코드 문법 및 이미지 생성 파일 검증과 계산 기반 검사만 완료. 브라우저에서 직접 플레이한 결과는 아닙니다.


## v1.1 캐릭터 이미지 교체
- 새로 제작한 그래픽 설계 시트에서 각 자세를 분리해 투명 PNG 60장으로 저장했습니다.
- `assets/idle_0.png` 등 기존 경로를 그대로 사용하므로 GitHub Pages에서 전체 폴더를 교체하면 됩니다.
- 일부 자세는 설계 시트의 원본 컷 수가 부족해 같은 컷을 재사용하며, 테두리 잔상이나 모션 전환이 남아 있을 수 있습니다.
- 실제 브라우저 플레이 테스트는 완료하지 않았습니다.
