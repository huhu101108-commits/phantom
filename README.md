# 환영 — 전투 프로토타입 v0.6

## 이번 업데이트: 주인공 전신 모션

승인된 은발·검은 모자·은빛 가면·검은 코트·흰 스카프 캐릭터 이미지를 여러 레이어로 나누어, 팔·다리·머리·망토·스카프를 각각 회전시키는 **2D 컷아웃 애니메이션**을 구현했습니다.

- 대기: 호흡, 머리와 스카프 미세 움직임
- 달리기: 양쪽 다리 교차, 팔 스윙, 망토 흔들림, 상체 기울기
- 점프/낙하: 별도 팔다리 자세 및 착지 압축
- Z: 3연속 공격에 따라 달라지는 검 휘두르기
- X: 순간이동과 흰 연막 등장 동작
- C: 폭탄 투척 팔 동작 + 후퇴 대시 자세
- V: 필살기 전용 검 휘두르기

이 버전은 정식 손그림 프레임 스프라이트가 아니라 **원본 일러스트를 분할한 컷아웃 리깅**입니다. 관절 경계나 의상 겹침은 추후 스프라이트별 수작업 보정이 필요할 수 있습니다.

## 실행 / 배포

`index.html`을 브라우저에서 실행하거나, 압축 해제한 **모든 파일 및 assets 폴더**를 GitHub 저장소 루트에 업로드하고 Settings → Pages에서 main / root를 선택하세요. 별도 설치/빌드가 필요하지 않습니다.

## 조작

←/→ 이동 · Space 점프 · Z 연속 검술 · X 흰 연막 순간이동 · C 후퇴 폭탄 · V 기세 필살기 · R 재시작

기존 적 AI, 전투 판정, 웨이브, 체력과 기세 게이지는 유지됩니다.
